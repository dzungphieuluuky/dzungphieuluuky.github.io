## Decisions (with rationale)

| Decision | Rationale |
|---|---|
| **Wave divide**: 1) Payload reduction, 2) Expensive CSS, 3) Housekeeping, 4) Verification | Each wave independently verifiable; no cross-wave file conflicts. |
| **Defer `!important` cleanup** | 37 of 68 are table overrides fighting Bootstrap — lower ROI than other tasks. |
| **Keep `@import` for pygment_highlights.css** | File doesn't exist on filesystem — comes from theme gem. Replacing would break build. |
| **Keep existing prefers-reduced-motion wrappers** | Already implemented in custom-styles.css:299-315 and 404.html:159-167. |
| **Keep existing prefers-color-scheme fallback** | Already implemented via `PREFER_DARK_MEDIA` in custom-script.js:8 and `DarkMode.init()`. |
| **No JS frameworks, no build tooling** | Static Jekyll site. Changes are plain CSS edits + one HTML edit. |
| **Keep `filter: grayscale` on post images** | Design intent — motion-safe wrapper already in place. |
| **Keep `backdrop-filter: blur` on 404 page** | Visual intent — only on one page. |
| **content-visibility only on post previews #4+** | Googlebot skips `content-visibility: auto` below-fold content; protects SEO for early posts. |
| **CSS containment NOT on `.navbar`** | `position: sticky` breaks inside `contain:` parents — confirmed by web standards. |

## Scope IN

1. Remove confirmed-dead selectors from beautifuljekyll.css (`.jumbotron`, `.hideme`, `.linked-section`, `.center`, `.intro-header .page-heading .post-subheading`, `.intro-header.big-img .page-heading hr`)
2. Remove confirmed-dead selectors from custom-styles.css (`.post-excerpt`, `.post-layout`, `.post-preview-tags`)
3. Prune bootstrap-social.css to 3 used social button variants (`btn-twitter`, `btn-facebook`, `btn-linkedin`)
4. Narrow universal `*` transition from 5 properties (color, background-color, border-color, opacity, box-shadow) to 2 properties (color, background-color); move the expensive properties to only the ~9 elements that actually need them
5. Fix `padding-left:hover` → `transform: translateX()` in tags.html; also update transition property at line 269
6. Add `contain: layout style` to `.blog-post article`, `.search-modal`, `.inline-toc`, `.lightbox-overlay`
7. Add `content-visibility: auto` + `contain-intrinsic-size` to `.posts-list .post-preview` items #4+ (below initial viewport)
8. Remove vendor prefixes confirmed unnecessary for browser target (Chrome 90+, Firefox 90+, Safari 15.4+, Edge 90+)
9. Merge two duplicate `prefers-reduced-motion` blocks into one
10. Fix `--shadow-lg` / `--shadow-xl` identical values (give `--shadow-xl` distinct larger value)
11. Fix pagination double-padding in beautifuljekyll.css (remove first redundant declaration)
