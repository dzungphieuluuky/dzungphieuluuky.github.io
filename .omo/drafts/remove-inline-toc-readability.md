## Findings (cited - path:lines)

### Current TOC System
- **Two TOCs exist on every post page.** The `.toc-wrapper > .inline-toc` sidebar (post.html:42-50) is generated by `PostTableOfContents.init()` at `custom-script.js:289-399`. The `.post-toc-box` is also generated by the same JS module inside `<article>` (lines 368-387).
- **Inline TOC is sidebar only on ≥1520px screens.** `custom-styles.css:888-914`: `.blog-post .toc-wrapper` is `display: none` by default; at ≥1520px, the blog-post becomes a CSS grid with a 220px sidebar column for the TOC. `.toc-wrapper` with 220px fixed width.
- **Inline TOC CSS is extensive:** 60+ lines for sidebar positioning, sticky behavior, scrollbar, nesting, expand/collapse toggles (`.toc-expand-toggle`) at `custom-styles.css:748-844`.
- **Dark mode inline TOC** covers `.inline-toc`, `.inline-toc-title`, links, and nesting (`custom-styles.css:1384-1392`).
- **Transition effects** exclude `.inline-toc a` from underline animation (`custom-styles.css:403-416`).
- **`TocHighlight` JS** queries both TOCs: `document.querySelectorAll('.inline-toc a, .toc-container a, .post-toc-box a')` at `custom-script.js:161`.

## Scope IN

1. **Remove inline/sidebar TOC** — delete `.toc-wrapper` + `.inline-toc` from `_layouts/post.html`, all CSS rules for `.toc-wrapper`, `.inline-toc`, `.toc-expand-toggle`, and the gutter/border `::before` pseudo-element. (`.toc-toggle-btn` exists only as JS-generated HTML — no CSS rules for it.)
2. **Update PostTableOfContents JS** — remove sidebar TOC generation code (`.toc-wrapper` + `.inline-toc` creation at lines 298-320, `buildTocItemsHtml()` at 325-353, HTML population at 366, expand/collapse click handler at 389-399). Keep `.post-toc-box` generation at lines 368-387 intact.
3. **Update TocHighlight** — change `line 161` querySelector from `'.inline-toc a, .toc-container a, .post-toc-box a'` to `'.post-toc-box a'` (`.toc-container a` is an orphaned selector — no `.toc-container` exists in any CSS or HTML).
4. **Update `.blog-post` layout** — remove the CSS grid layout (≥1520px breakpoint at lines 889-914) that creates a sidebar column. Blog-post returns to single-column centered layout with max-width 728px. Remove the `.blog-post .toc-wrapper { display: none; }` default rule at line 888.
5. **Polish `.post-toc-box`** — adjust margins/padding only (e.g., ensure it has enough visual weight as the sole TOC). No structural HTML changes. Current padding (0.75rem 1rem) is well within the AGENTS.md limit (1.25rem 1.5rem).
6. **Readability pass (Wowchemy reference)** — adjust figure/image top margins from 3rem to 2rem, figcaption bottom margin from 3rem to 2rem. Keep current paragraph line-height (1.8 Lora is deliberate — Wowchemy's 1.6 is too tight for Vietnamese diacritics).
7. **Clean up transition effects** — remove `.inline-toc a` from the underline-exclusion list at lines 404 and 412.
8. **Clean up `post-with-inline-toc` class** — rename to `post-layout` on line 8 of `_layouts/post.html` (this class has zero CSS rules — Bootstrap sizing comes from grid classes).
9. **Clean up dark mode** — remove `.inline-toc` overrides at lines 1384-1392.
10. **Clean up print styles** — remove `.toc-wrapper` from print `display: none` rules at line 1415.
11. **Build verification** — `bundle exec jekyll build --future` must exit 0. Manual check: a post page has one TOC at the top (`.post-toc-box`), no sidebar TOC.

## Edge Cases Verified

- **Posts with only H1 headings (no H2/H3):** `PostTableOfContents.init()` checks `if (headers.length < 1) return;` (JS line 323). H1-only posts will render `.post-toc-box` with H1 entries. `TocHighlight` checks `if (!headings.length) return;` (JS line 160). Both handle gracefully. Verified by reading JS init logic.
- **Posts with no headings at all:** Both PostTableOfContents and TocHighlight return early — no TOC rendered, no errors.
- **Mobile (<768px) and narrow (768-1519px) viewports:** Sidebar TOC was already `display: none` at these widths — removing it has zero visual impact on mobile.
- **Very wide (≥1520px) viewports:** Only affected viewport — sidebar TOC removed, blog-post returns to single-column. `.post-toc-box` inside article handles all TOC duties.
